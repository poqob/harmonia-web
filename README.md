# harmonia-web

Harmonia — Frekans Tabanlı Ses Terapi Uygulaması sunum web sitesi.

Nuxt 4 + Vue 3 + Tailwind CSS ile geliştirilmiştir.

## Komutlar

```bash
npm install
npm run dev      # localhost:3000
npm run build    # production build → .output/public
```

## Deployment

Cloudflare Pages'e deploy edilir. `wrangler.toml` yapılandırması mevcuttur.
